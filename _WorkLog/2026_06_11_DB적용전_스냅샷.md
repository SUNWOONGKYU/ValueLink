## 5. FK 관계

PostgREST information_schema 쿼리는 미지원으로 직접 조회 불가.
postgres 직결 연결도 ENOTFOUND(네트워크 차단)로 실패.

**알려진 FK 관계 (코드 분석 기반)**:
- `valuation_results.project_id` → `projects.project_id` (추정)
- `projects.customer_id` → `customers.customer_id` (구 스키마)
- `approval_points` → (v4: workflow_approvals 참조 추정)

## 6. DDL 실행 경로 확보 결과

| 경로 | 결과 | 실패 이유 |
|------|------|-----------|
| (a) postgres 직결 (db.{ref}.supabase.co:5432) | ❌ 실패 | getaddrinfo ENOTFOUND — IPv6/네트워크 차단 |
| (a) Pooler Transaction mode (6543) | ❌ 실패 | ENOTFOUND — 풀러 호스트명 차단 |
| (a) Pooler Session mode (5432) | ❌ 실패 | ENOTFOUND — 풀러 호스트명 차단 |
| (b) supabase CLI (npx supabase link) | ❌ 실패 | Docker daemon not running |
| (c) Management API /v1/projects/{ref}/database/query | ❌ 차단 | Personal Access Token(PAT) 없음 |
| (c) PostgREST RPC exec_sql | ❌ 없음 | 함수 미등록 (PGRST202) |
| (c) Edge Function | ❌ 없음 | 404 |
