## 14단계 워크플로우 상세 가이드

ValueLink는 14단계 워크플로우를 통해 기업 평가를 체계적으로 진행합니다.

### Step 1: 평가 의뢰 생성

**목적**: 고객이 기업 평가를 요청합니다.

**필수 정보**:
- 프로젝트명 (예: "ABC 기업 DCF 평가")
- 회사명 (한글) (예: "ABC 주식회사")
- 평가 방법 (DCF, Relative, Asset, Intrinsic, Tax 중 선택)
- 산업 분류 (예: "제조업 - 반도체")

**화면 예시**:
```
┌──────────────────────────────────────────────┐
│         평가 의뢰 생성 페이지                  │
├──────────────────────────────────────────────┤
│                                              │
│  프로젝트명                                   │
│  ┌────────────────────────────────────────┐ │
│  │ ABC 기업 DCF 평가                       │ │
│  └────────────────────────────────────────┘ │
│                                              │
│  회사명 (한글)                                │
│  ┌────────────────────────────────────────┐ │
│  │ ABC 주식회사                            │ │
│  └────────────────────────────────────────┘ │
│                                              │
│  평가 방법                                    │
│  ┌────────────────────────────────────────┐ │
│  │ DCF (Discounted Cash Flow)            │ │
│  │ ├─ Relative (비교 평가)                │ │
│  │ ├─ Asset (자산 평가)                   │ │
│  │ ├─ Intrinsic (본질가치)                │ │
│  │ └─ Tax (세무 평가)                     │ │
│  └────────────────────────────────────────┘ │
│                                              │
│  산업 분류                                    │
│  ┌────────────────────────────────────────┐ │
│  │ 제조업 - 반도체                          │ │
│  └────────────────────────────────────────┘ │
│                                              │
│  [ 견적 요청 ]                                │
│                                              │
└──────────────────────────────────────────────┘
```

**다음 단계**: Step 2 (견적 제시)

**팁**: 평가 방법은 회사 특성에 맞게 선택하세요. (FAQ 참조)

---

### Step 2: 견적 제시

**목적**: 회계사가 평가 비용을 제시합니다.

**견적 산출 기준**:
- 기본 요율: 500만원
- 평가 방법별 가중치:
  - DCF: 1.5x (가장 상세한 분석)
  - Relative: 1.0x (기준)
  - Asset: 1.2x
  - Intrinsic: 1.1x
  - Tax: 0.9x (기본 분석)
- 산업별 가중치:
  - IT/전자: 1.3x (복잡한 구조)
  - 제조업: 1.2x
  - 금융/보험: 1.4x
  - 기타: 1.0x
- 회사 규모별 가중치:
  - 매출 100억 미만: 1.0x
  - 매출 100-500억: 1.5x
  - 매출 500억 이상: 2.0x

**예시 계산**:
```
기본 요율: 500만원
평가 방법 선택: DCF (1.5x)
산업 분류: 제조업 (1.2x)
회사 규모: 매출 150억 (1.5x)

총 견적: 500 × 1.5 × 1.2 × 1.5 = 1,350만원
```

**화면 예시**:
```

│            견적서 - 평가 비용 안내             │
├──────────────────────────────────────────────┤
│                                              │

│  회사명: ABC 주식회사                         │
│  평가 방법: DCF                              │
│                                              │
│  ┌──────────────────────────────────────┐  │
│  │ 비용 산출 내역                        │  │
│  ├──────────────────────────────────────┤  │
│  │ 기본 요율          500만원            │  │
│  │ 평가 방법(1.5x)   +250만원           │  │
│  │ 산업(1.2x)        +100만원           │  │
│  │ 규모(1.5x)        +500만원           │  │
│  │ ──────────────────────────────      │  │

```

**팁**: 견적이 높으면 협상 요청으로 평가 범위를 축소할 수 있습니다.

### Step 3: 평가 협약

**목적**: 고객과 회계사가 평가 범위와 일정을 협의합니다.

**협약 항목**:
- 최종 비용 확정
- 평가 일정 확정 (완료 목표일)
- 필요한 자료 목록
- 회의 일정 (자료 설명)

### Step 4: 문서 업로드

**목적**: 고객이 필요한 재무 자료를 업로드합니다.

**필수 문서**:
- **재무제표**: 최근 3개년 (손익계산서, 재무상태표, 현금흐름표)
- **사업 계획서**: 향후 5년 매출/이익 예측
- **산업 분석 자료**: 산업 현황 및 전망
- **기타**: CEO 약력, 주요 고객 목록 등 (선택)

**파일 형식**: PDF, Excel, Word (.pdf, .xlsx, .docx)

**화면 예시**:
```

**다음 단계**: Step 5 (문서 검토)

### Step 5: 문서 검토

**목적**: 회계사가 업로드된 문서를 검토하고 추가 자료를 요청합니다.

**검토 항목**:
- 문서 완전성: 필수 자료 모두 포함?
- 재무데이터 일관성: 3개년 연속성 확인
- 사업 계획 타당성: 매출 예측이 산업 현황과 일치?
- 자료 품질: 명확하고 읽을 수 있는가?

**상태 변화**:
- ✓ 모든 검증 통과 → Step 6 (기초 분석)로 진행
- ✗ 추가 자료 필요 → Step 4로 돌아가서 재업로드

**다음 단계**: Step 6 (기초 분석)

### Step 6: 기초 분석

**목적**: 회계사가 업로드된 데이터의 기초 분석을 수행합니다.

**분석 항목**:
- **매출 분석**: 최근 3개년 성장률, 성장 추세
- **수익성 분석**: EBITDA 마진, 순이익률 추이
- **현금 흐름 분석**: 영업 현금흐름, 자유 현금흐름
- **안정성 분석**: 부채비율, 유동비율 등

**결과 예시**:
```
ABC 주식회사 기초 분석 결과

1. 매출 성장
   - 2023: 100억원
   - 2024: 130억원 (+30%)
   - 2025: 185억원 (+42%)
   - 평균 성장률: 36%

2. 수익성
   - EBITDA 마진: 25% (업계 평균 22%)
   - 순이익률: 15% (업계 평균 12%)
   - 추세: 개선 중 (↑)

3. 현금 흐름
   - 영업 현금흐름: 23억원
   - 자유 현금흐름: 15억원
   - 현금 보유: 10억원

4. 안정성
   - 부채비율: 40% (업계 평균 65%)
   - 안정성: 우수 (↑)
```

**다음 단계**: Step 7 (가정 설정)

---

### Step 7: 가정 설정

**목적**: 회계사와 고객이 평가에 필요한 주요 가정을 협의합니다.

**주요 가정** (DCF의 경우):
- **매출 성장률**: 향후 5년 연평균 성장률
- **EBITDA 마진**: 영업 이익 마진
- **자본금 회수율**: 매년 필요한 투자 비율
- **가중평균자본비용 (WACC)**: 할인율
- **영속 성장률**: 5년 이후 영구 성장률

**협의 예시**:
```
기초 분석 기반 가정 제시

1. 매출 성장률
   - 기초분석 결과: 평균 36% 증가
   - 제시 가정: 향후 5년 20% (업계 성장 둔화 감안)
   - 고객 피드백: 동의 ✓

2. EBITDA 마진
   - 기초분석 결과: 25%
   - 제시 가정: 유지 25%
   - 고객 피드백: 동의 ✓

3. WACC (할인율)
   - 시장 평균: 12%
   - 회사 위험도: 중간 (스타트업)
   - 제시 가정: 15%
   - 고객 피드백: 검토 중...

4. 영속 성장률
   - 장기 GDP 성장률: 3%
   - 제시 가정: 3%
   - 고객 피드백: 동의 ✓
```

**다음 단계**: Step 8 (평가 계산)

---

### Step 8: 평가 계산

**목적**: 회계사가 설정된 가정을 기반으로 평가 계산을 수행합니다.

**계산 과정** (DCF의 경우):
```
Step 1: 5년 매출 예측
├─ 현재 매출: 185억원
├─ 성장률: 20%
└─ 결과: Year 1 (222억), Year 2 (266억), ... Year 5 (457억)

Step 2: FCF (자유 현금흐름) 계산
├─ 매출 × EBITDA 마진 = EBITDA
├─ EBITDA - 세금 - 투자 = FCF
└─ 결과: Year 1 (29억), Year 2 (35억), ... Year 5 (56억)

Step 3: DCF (현재가치) 계산
├─ 각 연도 FCF를 WACC로 할인
├─ 할인율: WACC 15%
└─ 결과: PV Year 1 (25억), PV Year 2 (26억), ... 합계 (115억)

Step 4: Terminal Value (종료가치)
├─ Year 5 FCF × (1 + 영속 성장률) / (WACC - 성장률)
├─ = 56억 × 1.03 / (0.15 - 0.03)
└─ 결과: 480억원 → 현재가치: 237억원

Step 5: 기업 가치 (EV)
├─ DCF 합계 + Terminal Value 현재가치
└─ = 115억 + 237억 = 352억원

Step 6: 주주 가치 (Equity Value)
├─ 기업 가치 + 현금 - 부채
└─ = 352억 + 10억 - 14억 = 348억원
```

**결과 요약**:
```
평가 결과

기업 가치 (Enterprise Value): 352억원
주주 가치 (Equity Value): 348억원

주요 지표:
- P/E (Price-to-Earnings): 18배
- EV/EBITDA: 14배
- PEG (성장 고려): 0.7배 (저평가 상태)
```

**다음 단계**: Step 9 (민감도 분석)

### Step 9: 민감도 분석

**목적**: 주요 가정 변화에 따른 평가가의 변동성을 분석합니다.

**분석 항목**:
- WACC (할인율) 변화 영향
- 매출 성장률 변화 영향
- EBITDA 마진 변화 영향

**결과 예시**:
```
민감도 분석 표 (기업 가치 기준)

WACC vs 성장률:
                매출 성장 15%   20%      25%      30%
                ───────────────────────────────────────
WACC 12%        420억         480억     560억    650억
     13%        380억         430억     485억    550억
     14%        340억         385억     430억    480억
     15%        300억         352억     385억    428억 ← 기본 가정
     16%        270억         310억     345억    380억

분석:
- 저 WACC (12%) + 고 성장(30%) → 650억원 (상승 시나리오)
- 고 WACC (16%) + 저 성장(15%) → 270억원 (하강 시나리오)
- 기본 가정 (WACC 15%, 성장 20%) → 352억원 (중간값)
```

**해석 팁**: 민감도 분석은 평가의 범위를 보여줍니다. 각 시나리오는 가정 변화에 따른 영향을 나타냅니다.

**다음 단계**: Step 10 (비교 분석)

---

### Step 10: 비교 분석

**목적**: 같은 산업의 비슷한 회사와 평가 결과를 비교합니다.

**비교 회사 선정**:
- 같은 산업 (IT)
- 유사한 매출 규모 (100-300억)
- 유사한 성장률 (15-30%)

**비교 예시**:
```
비교 분석 (제조업 - 반도체 산업)

                ABC사 (평가대상)  경쟁사 1    경쟁사 2    산업 평균
─────────────────────────────────────────────────────────
매출             185억          200억      150억      178억
성장률           36%            25%        20%        27%
P/E 배수         18배           20배       16배       18배
EV/EBITDA       14배           16배       12배       14배
PEG 배수         0.7배          0.8배      0.8배      0.77배

평가
- ABC사 P/E(18배)는 산업 평균(18배)과 동일
- ABC사는 높은 성장률(36%) 대비 저평가 상태 (PEG 0.7 < 1.0)
- 장기 성장 투자 관점에서 매력적
```

**다음 단계**: Step 11 (최종 평가)

### Step 11: 최종 평가

**목적**: 지금까지의 분석을 종합하여 최종 평가가를 도출합니다.

**평가 방법별 결과**:
```
평가 방법별 결과 (ABC 주식회사)

1. DCF 평가: 352억원
   - 자유 현금흐름 기반 분석
   - 향후 5년 20% 성장률 가정
   - 신뢰도: ★★★★★ (높음, 데이터 충분)

2. Relative 평가: 340억원
   - 비교 회사 P/E 18배 적용
   - 순이익 19억원 × 18배
   - 신뢰도: ★★★★☆ (중상, 비교 회사 유사도 85%)

3. Asset 평가: 280억원
   - 순자산 + 영업권
   - 자산 기반 보수적 평가
   - 신뢰도: ★★★☆☆ (중하, 성장성 미반영)

최종 평가가: 330억원 (3개 방법의 가중 평균)
평가 범위: 280억 ~ 380억원 (민감도 분석 기반)
```

**다음 단계**: Step 12 (평가 보고서)

## 자주 묻는 질문 (FAQ)

### Q1: 평가 방법을 어떻게 선택해야 하나요?

**A**: 회사 상황에 따라 다릅니다. 다음 표를 참고하세요:

| 평가 방법 | 적합한 경우 | 예시 | 특징 |
|----------|------------|------|------|
| **DCF** | 안정적 현금흐름, 빠른 성장 | IT 스타트업, 유망 제조업 | 가장 정밀, 비용 높음 |
| **Relative** | 비슷한 상장사 많음 | 음식점, 프랜차이즈 | 빠른 평가, 객관적 |
| **Asset** | 자산 가치 중심 | 부동산, 자산 보유사 | 보수적, 간단 |
| **Intrinsic** | ROE 중시 | 은행, 보험, 금융사 | ROE 기반, 금융사 특화 |
| **Tax** | 세무 목적 | 상속, 증여, 감정평가 | 법적 근거, 기본 분석 |

**추천**:
- **빠른 성장 기업** → DCF (성장성 반영 가능)
- **안정적 기업** → Relative 또는 Asset (객관성)
- **금융 기업** → Intrinsic (ROE 기반)
- **세무 용도** → Tax (법적 효력)

---

### Q2: 평가 기간은 얼마나 걸리나요?

**A**: 평균 **2-3주** 소요됩니다.

**단계별 소요 시간**:
```
Step 1-3 (의뢰~협약): 3일
  ├─ 의뢰 생성: 1시간
  ├─ 견적 제시: 1일
  └─ 협약 체결: 1일

Step 4-6 (문서~기초분석): 7일
  ├─ 문서 업로드: 3일 (고객 준비)
  ├─ 문서 검토: 1일
  └─ 기초 분석: 3일

Step 7-9 (가정~민감도분석): 5일
  ├─ 가정 설정: 2일 (협의)
  ├─ 평가 계산: 1일
  └─ 민감도 분석: 2일

Step 10-14 (비교~납품): 4일
  ├─ 비교 분석: 1일
  ├─ 최종 평가: 1일
  ├─ 보고서 작성: 1일
  └─ 최종 납품: 1일

총 기간: 19일 (≈ 3주)
```

**팁**: 문서 준비가 빠를수록 전체 일정이 단축됩니다.

### Q3: 필요한 재무 자료는 무엇인가요?

**A**: 평가 방법별로 다릅니다.

**DCF 평가 (필수)**:
- 최근 3개년 재무제표
  - 손익계산서 (P&L)
  - 재무상태표 (Balance Sheet)
  - 현금흐름표 (Cash Flow)
- 사업 계획서 (향후 5년)
  - 매출 예측
  - 이익률 전망
  - 투자 계획
- 산업 분석 자료

**Relative 평가 (필수)**:
- 최근 1-2개년 재무제표 (위와 동일)
- 비교 회사 선정 정보

**Asset 평가 (필수)**:
- 재무상태표 (자산 목록)
- 자산 감정 자료 (부동산 등)

**필수 문서 체크리스트**:
- [ ] 손익계산서 (최근 3개년)
- [ ] 재무상태표 (최근 3개년)
- [ ] 현금흐름표 (최근 3개년)
- [ ] 사업 계획서 (5년)
- [ ] 산업 분석 자료
- [ ] 기타 자료 (CEO 약력, 고객 목록 등)

### Q4: 평가 보고서는 어디에 사용할 수 있나요?

**A**: 다양한 용도로 활용 가능합니다.

**주요 사용처**:

| 용도 | 활용 방법 | 예시 |
|------|----------|------|
| **투자 의사결정** | 투자자에게 제출 | 벤처 펀딩, M&A 협상 |
| **금융 대출** | 은행에 제출 | 기업 대출, 신용평가 |
| **세무 용도** | 국세청 제출 | 상속세, 증여세 계산 |
| **내부 관리** | 경영진 보고용 | 성과 평가, 전략 수립 |
| **거래 협상** | 협상 참고 | 회사 인수, 지분 거래 |

**팁**: 평가 보고서는 객관적인 기준으로 인정받으므로 협상 시 설득력이 높습니다.

| 상황 | 법적 효력 | 비고 |

| **보험 감정** | ✓ 있음 | 보험사 인정 |
| **거래 증명** | △ 참고용 | 당사자 합의 필요 |
| **법원 증거** | △ 참고용 | 법관 판단 기준 |

### Q6: 평가 결과가 만족스럽지 않으면 어떻게 하나요?

**A**: 다음 옵션이 있습니다.

**선택지**:

1. **가정 재협의** (1-2일 소요)
   - 매출 성장률, WACC 등 재조정
   - 재분석 비용: 추가 없음
   - 적합한 경우: 합의되지 않은 가정

2. **평가 방법 변경** (1주 소요)
   - DCF → Relative 변경 등
   - 추가 비용: 원가 기준
   - 적합한 경우: 다른 관점에서 평가 필요

3. **재평가** (2-3주 소요)
   - 전체 과정 재수행
   - 추가 비용: 50% (기존 비용 기준)
   - 적합한 경우: 새로운 데이터 추가

4. **제2의 평가** (외부 기관)
   - 다른 회계사에게 평가 의뢰
   - 비용: 별도 협약
   - 적합한 경우: 객관성 확보 필요

**팁**: 만족도가 낮으면 먼저 "가정 재협의"부터 시작하는 것이 경제적입니다.

| **기본 분석만** | 40-50% | Tax 평가만 선택 |
| **자료 사전 준비** | 10-20% | 시간 절감 |
| **분기별 정기 평가** | 30% | 연 4회 계약 |

**추천 조합**:
- 상황 1: "Relative 평가 + 분기별 정기" → 비용 50% 절감
- 상황 2: "Asset 평가 + 범위 축소" → 비용 30% 절감
- 상황 3: "Tax 평가만" → 비용 40% 절감

## 문제 해결 가이드

### 문제 1: "견적이 너무 높아요. 어떻게 해야 하나요?"

**원인 분석**:
```
견적 구성 = 기본 요율 × 평가 방법 × 산업 × 규모

1,350만원 = 500 × 1.5(DCF) × 1.2(제조) × 1.5(규모)
```

**해결 방법**:

**방법 1: 평가 방법 변경** (최대 50% 절감)
```
현재: DCF × 1.5 = 1,350만원
변경: Relative × 1.0 = 600만원 (55% 절감)

절충: Asset × 1.2 = 864만원 (36% 절감)
```

**방법 2: 평가 범위 축소** (10-30% 절감)
```
현재 범위: 전체 기업
축소 범위: 핵심 사업만

추정 절감: 20-30%
```

**방법 3: 분할 납부 협의** (현금흐름 개선)
```
일시 납부: 1,350만원
분할 납부: 500만원(선금) + 850만원(기말)
```

**방법 4: 장기 계약 할인** (정기 평가, 30% 절감)
```
1회: 1,350만원
정기(분기별): 1,350만원 × 4 × 70% = 3,780만원/년 (1회당 945만원)
```

**추천**: 투자자 협상이 목적이면 **DCF 평가** 유지, 내부용이면 **Relative로 변경**

│    ↓                                 │
│ 5. 업로드 완료 버튼 클릭              │
│                                      │

```

**팁**: 파일명은 명확하게 (예: "2025_손익계산서_최종.xlsx")

### 문제 3: "평가 과정에서 회계사와 연락이 안 돼요."

**해결 방법**:

**Step 1: 연락 시도 (우선순위)**
```
1순위: 이메일 (공식 기록 남음)
   예: contact@valuelink.co.kr
   제목: "[프로젝트번호] 상담 요청"

2순위: 전화 (긴급 시)
   대표번호: 02-XXXX-XXXX
   담당자 직통: 010-XXXX-XXXX

3순위: 웹사이트 채팅 (실시간)
   www.valuelink.co.kr → 상담 채팅 버튼
```

**Step 2: 연락 내용 명확히 하기**
```
효과적인 연락:
"프로젝트 ABC-001 평가 진행 상황 확인 및
Step 5 문서 검토 결과 설명 요청"

비효과적인 연락:
"평가는 어떻게 되어가고 있나요?"
```

**Step 3: 대응 시간 기준**
```
이메일: 24시간 내 회신
전화: 당일 회신 (업무 시간)
웹 채팅: 10분 내 회신 (상담사 대기 시)

휴무일 (토/일/공휴일): 다음 업무일 회신
```

**팁**: 규칙적인 진행 상황 보고를 요청하면 소통이 원활합니다.

### 문제 4: "평가 과정 중 추가 비용이 발생했어요."

**예상 상황**:
```
상황 1: 추가 자료 요청으로 기간 연장
상황 2: 가정 재협의로 분석 재수행
상황 3: 평가 방법 변경
상황 4: 보고서 추가 수정
```

**처리 방법**:

**Step 1: 비용 발생 원인 확인**
```
회계사에게 확인:
- 추가 비용이 발생한 정확한 이유?
- 사전 계약에 명시되었는가?
- 정산 방식은?
```

**Step 2: 계약 조항 검토**
```
계약서 확인:
- 기본 서비스 범위
- 추가 서비스 비용 규정
- 분쟁 해결 절차
```

**Step 3: 비용 조정 협의**
```
협의 포인트:
1. 추가 비용이 필수인가?
2. 대안이 있는가? (범위 축소 등)
3. 분할 납부 가능한가?
```

**팁**: 계약 전에 "추가 비용 발생 가능성"을 명확히 하세요.

### 문제 5: "보고서를 다시 받고 싶은데 가능한가요?"

**해결 방법**:

**보고서 종류**:
```
1. 원본 보고서 (인쇄본, 서명 인감)
   - 법적 효력 O
   - 재발급: 비용 없음 (저장 재출력)

2. PDF 사본 (전자 버전)
   - 법적 효력 △ (원본 인정 필요)
   - 재발급: 즉시 가능 (메일)

3. 수정된 보고서 (가정 변경 후)
   - 법적 효력 O (새 버전)
   - 추가 비용: 50%

4. 축약 버전 (요약 보고서)
   - 법적 효력 △ (참고용)
   - 추가 비용: 없음
```

**재발급 요청 방법**:
```
Step 1: 회계사에게 이메일
   제목: "보고서 재발급 요청"
   내용:
   - 프로젝트번호
   - 필요한 형식 (인쇄본/PDF/축약)
   - 사유 (분실/추가 제출 등)

Step 2: 확인 후 재발급
   일반적으로 3-5 업무일 소요
```

**팁**: 중요한 보고서는 인쇄본 + PDF 모두 보관하세요.
