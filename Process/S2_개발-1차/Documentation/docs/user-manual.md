## 1. 시작하기

### 1.1 회원가입

ValueLink 회원가입은 3단계로 진행됩니다.

#### Step 1: 기본정보 입력

1. ValueLink 홈페이지에 접속합니다.
2. 우측 상단의 **"회원가입"** 버튼을 클릭합니다.
3. 아래 정보를 입력합니다.
   - **이메일 주소** (로그인 ID로 사용됩니다)
   - **비밀번호** (8자 이상, 영문+숫자+특수문자 포함 권장)
   - **비밀번호 확인**
   - **이름**

#### Step 2: 역할 선택

가입 시 아래 4가지 역할 중 하나를 선택합니다.

| 역할 | 설명 | 주요 기능 |
|------|------|----------|
| **고객** | 기업가치평가를 의뢰하는 사용자 | 프로젝트 생성, 평가 신청, 보고서 수령 |
| **회계사** | 평가 업무를 수행하는 전문가 | 프로젝트 검토, 보고서 작성, 수정 반영 |
| **관리자** | 플랫폼 운영 및 관리 담당자 | 전체 프로젝트 관리, 담당자 배정, 승인 |
| **투자자** | 평가 결과를 열람하는 투자 관계자 | 보고서 열람, 포트폴리오 관리 |

#### Step 3: 추가정보 입력

역할에 따라 추가 정보를 입력합니다.

- **고객**: 회사명, 업종, 담당자 연락처
- **회계사**: 소속 법인, 자격증 번호, 전문 분야
- **투자자**: 소속 기관, 투자 분야

모든 정보를 입력하고 **"가입 완료"** 버튼을 클릭하면 등록된 이메일로 인증 메일이 발송됩니다. 이메일 인증을 완료하면 서비스를 이용할 수 있습니다.

---

### 1.2 로그인

1. ValueLink 홈페이지에 접속합니다.
2. 우측 상단의 **"로그인"** 버튼을 클릭합니다.
3. **이메일 주소**와 **비밀번호**를 입력합니다.
4. **"로그인"** 버튼을 클릭합니다.

> **참고**: 로그인 상태는 브라우저를 닫을 때까지 유지됩니다. 공용 컴퓨터를 사용하는 경우 반드시 로그아웃해 주세요.

---

### 1.3 비밀번호 찾기

1. 로그인 페이지에서 **"비밀번호를 잊으셨나요?"** 링크를 클릭합니다.
2. 가입 시 사용한 **이메일 주소**를 입력합니다.
3. **"비밀번호 재설정 링크 보내기"** 버튼을 클릭합니다.
4. 이메일로 전송된 재설정 링크를 클릭합니다.
5. 새 비밀번호를 입력하고 확인합니다.

> **주의**: 비밀번호 재설정 링크는 발송 후 **24시간** 동안만 유효합니다.

---

## 2. 프로젝트 생성

### 2.1 프로젝트 목록 페이지 접속

1. 로그인 후, 좌측 사이드바 또는 대시보드에서 **"프로젝트"** 메뉴를 클릭합니다.
2. 프로젝트 목록 페이지에서 현재 진행 중이거나 완료된 프로젝트를 확인할 수 있습니다.
3. 새 프로젝트를 시작하려면 **"새 프로젝트 만들기"** 버튼을 클릭합니다.

### 2.2 프로젝트 정보 입력

프로젝트 생성 양식에 아래 정보를 입력합니다.

| 항목 | 설명 | 필수 여부 |
|------|------|:---------:|
| 프로젝트명 | 평가 대상 기업명 또는 프로젝트 식별 이름 | 필수 |
| 평가 방법 선택 | DCF, Relative, Asset, Intrinsic, Tax 중 선택 | 필수 |
| 평가 목적 | 투자 유치, M&A, 세무 신고, 내부 관리 등 | 선택 |
| 기준일 | 평가 기준이 되는 날짜 | 선택 |
| 비고 | 추가 참고 사항 | 선택 |

### 2.3 프로젝트 생성 완료

1. 입력 내용을 확인합니다.
2. **"프로젝트 생성"** 버튼을 클릭합니다.
3. 프로젝트가 생성되면 프로젝트 상세 페이지로 이동합니다.
4. 이후 견적 요청 및 결제 절차가 진행됩니다.

---

## 3. 평가 신청

ValueLink에서는 5가지 기업가치평가 방법을 제공합니다. 기업의 상황과 평가 목적에 맞는 방법을 선택해 주세요.

### 평가 방법 비교표

| 평가 방법 | 가격 | 소요 기간 | 적합한 기업 |
|----------|------|----------|------------|
| DCF (현금흐름할인법) | 800만원 | 약 10영업일 | 안정적 현금흐름이 있는 기업 |
| Relative (상대가치평가) | 500만원 | 약 7영업일 | 유사 기업이 많은 업종 |
| Asset (자산가치평가) | 600만원 | 약 8영업일 | 부동산, 유형자산 비중이 높은 기업 |
| Intrinsic (내재가치평가) | 600만원 | 약 8영업일 | 기술력, 브랜드 가치가 높은 기업 |
| Tax (세법상평가) | 1,000만원 | 약 12영업일 | 세무 신고, 상속/증여 목적 |

---

### 3.1 DCF (현금흐름할인법)

**DCF (Discounted Cash Flow, 현금흐름할인법)**는 미래에 기업이 창출할 현금흐름을 현재 가치로 환산하여 기업의 가치를 산정하는 방법입니다.

- **가격**: 800만원 (부가세 별도)
- **소요 기간**: 약 10영업일
- **적합한 기업**: 매출과 영업이익이 안정적이며, 향후 현금흐름 예측이 가능한 기업
- **주요 활용 목적**: 투자 유치, M&A, 전략적 의사결정

**신청 절차:**
1. 프로젝트 생성 시 평가 방법에서 **"DCF"** 를 선택합니다.
2. 견적 요청 후 견적서를 확인합니다.
3. 결제를 완료합니다.
4. 필요 자료(재무제표, 사업계획서 등)를 제출합니다.

---

### 3.2 Relative (상대가치평가)

**Relative Valuation (상대가치평가)**은 유사한 업종이나 규모의 상장 기업과 비교하여 기업가치를 산정하는 방법입니다. PER(주가수익비율), PBR(주가순자산비율), EV/EBITDA 등의 지표를 활용합니다.

- **가격**: 500만원 (부가세 별도)
- **소요 기간**: 약 7영업일
- **적합한 기업**: 동일 업종에 비교 가능한 상장 기업이 존재하는 경우
- **주요 활용 목적**: 시장 기반 가치 파악, IPO 준비, 벤치마킹

**신청 절차:**
1. 프로젝트 생성 시 평가 방법에서 **"Relative"** 를 선택합니다.
2. 견적 요청 후 견적서를 확인합니다.
3. 결제를 완료합니다.
4. 필요 자료(재무제표, 비교 기업 목록 등)를 제출합니다.

---

### 3.3 Asset (자산가치평가)

**Asset-based Valuation (자산가치평가)**은 기업이 보유한 자산에서 부채를 차감하여 순자산 가치를 기반으로 기업가치를 산정하는 방법입니다.

- **가격**: 600만원 (부가세 별도)
- **소요 기간**: 약 8영업일
- **적합한 기업**: 부동산, 설비 등 유형자산의 비중이 높은 기업, 지주회사
- **주요 활용 목적**: 청산 가치 파악, 자산 중심 기업 평가, 부동산 보유 법인

**신청 절차:**
1. 프로젝트 생성 시 평가 방법에서 **"Asset"** 을 선택합니다.
2. 견적 요청 후 견적서를 확인합니다.
3. 결제를 완료합니다.
4. 필요 자료(재무제표, 자산 목록, 감정평가서 등)를 제출합니다.

---

### 3.4 Intrinsic (내재가치평가)

**Intrinsic Valuation (내재가치평가)**은 기업의 기술력, 브랜드 가치, 특허, 인적자원 등 무형의 내재적 가치를 종합적으로 반영하여 기업가치를 산정하는 방법입니다.

- **가격**: 600만원 (부가세 별도)
- **소요 기간**: 약 8영업일
- **적합한 기업**: 기술 기반 스타트업, 브랜드 가치가 높은 기업, IP(지식재산) 보유 기업
- **주요 활용 목적**: 기술 가치 입증, 투자 협상, 지식재산 거래

**신청 절차:**
1. 프로젝트 생성 시 평가 방법에서 **"Intrinsic"** 을 선택합니다.
2. 견적 요청 후 견적서를 확인합니다.
3. 결제를 완료합니다.
4. 필요 자료(재무제표, 기술 설명서, 특허 목록 등)를 제출합니다.

---

### 3.5 Tax (세법상평가)

**Tax Valuation (세법상평가)**은 상속세 및 증여세법, 법인세법 등 세법에서 정한 방식에 따라 기업가치를 산정하는 방법입니다. 법적 효력을 가지는 평가로, 세무 신고 시 필수적으로 활용됩니다.

- **가격**: 1,000만원 (부가세 별도)
- **소요 기간**: 약 12영업일
- **적합한 기업**: 비상장 주식의 상속/증여, 합병/분할 시 주식 가액 산정이 필요한 기업
- **주요 활용 목적**: 상속세 신고, 증여세 신고, 합병/분할 가액 산정

**신청 절차:**
1. 프로젝트 생성 시 평가 방법에서 **"Tax"** 를 선택합니다.
2. 견적 요청 후 견적서를 확인합니다.
3. 결제를 완료합니다.
4. 필요 자료(재무제표 3개년, 주주명부, 세무 관련 서류 등)를 제출합니다.

> **참고**: 세법상평가는 법적 요건이 엄격하므로 다른 평가 방법 대비 소요 기간이 길고 비용이 높습니다. 정확한 세무 신고를 위해 전문 회계사의 면밀한 검토가 이루어집니다.

## 4. 진행 상황 확인

ValueLink의 기업가치평가 프로젝트는 총 **14단계**의 워크플로우로 진행됩니다. 각 단계의 진행 상황은 프로젝트 상세 페이지에서 실시간으로 확인할 수 있습니다.

### 14단계 워크플로우

| 단계 | 이름 | 담당 | 설명 |
|:----:|------|------|------|
| 1 | **프로젝트 생성** | 고객 | 프로젝트를 생성하고 평가 방법을 선택합니다. |
| 2 | **견적 요청** | 고객 | 선택한 평가 방법에 대한 견적을 요청합니다. |
| 3 | **견적 확인** | 고객 | 발행된 견적서의 금액과 조건을 확인합니다. |
| 4 | **결제** | 고객 | 무통장 입금으로 결제를 완료합니다. |
| 5 | **자료 제출** | 고객 | 평가에 필요한 재무제표, 사업계획서 등을 업로드합니다. |
| 6 | **담당자 배정** | 관리자 | 해당 프로젝트에 전문 회계사를 배정합니다. |
| 7 | **자료 검토** | 회계사 | 제출된 자료의 완전성과 정확성을 검토합니다. |
| 8 | **AI 초안 생성** | 시스템 | AI가 제출된 자료를 분석하여 평가 보고서 초안을 생성합니다. |
| 9 | **전문가 검토** | 회계사 | AI 초안을 전문 회계사가 검토하고 보완합니다. |
| 10 | **수정 요청/반영** | 고객/회계사 | 고객이 수정을 요청하면 회계사가 반영합니다. |
| 11 | **최종 보고서 작성** | 회계사 | 모든 검토와 수정을 반영한 최종 보고서를 작성합니다. |
| 12 | **내부 승인** | 관리자 | 최종 보고서의 품질과 정확성에 대한 내부 승인을 진행합니다. |
| 13 | **보고서 발송** | 시스템 | 승인된 보고서를 고객에게 발송합니다. |
| 14 | **완료** | - | 프로젝트가 완료되고 보고서 다운로드가 가능합니다. |

### 진행 상황 확인 방법

1. 로그인 후 **"프로젝트"** 메뉴로 이동합니다.
2. 해당 프로젝트를 클릭하여 상세 페이지에 접속합니다.
3. 상단 진행 상태 바에서 현재 단계를 확인합니다.
4. 각 단계의 완료 일시와 담당자 정보를 확인할 수 있습니다.

> **참고**: 단계가 전환될 때마다 등록된 이메일로 알림이 발송됩니다.

## 5. 보고서 다운로드

### 보고서 목록 확인

1. 로그인 후 **"프로젝트"** 메뉴로 이동합니다.
2. 완료된 프로젝트(14단계 완료)를 클릭합니다.
3. **"보고서"** 탭을 클릭하면 발행된 보고서 목록을 확인할 수 있습니다.

### PDF 다운로드

1. 보고서 목록에서 다운로드할 보고서의 **"다운로드"** 버튼을 클릭합니다.
2. 서명된 URL(Signed URL)이 생성되어 PDF 파일이 다운로드됩니다.
3. 다운로드된 파일은 PDF 형식이며, 디지털 서명이 포함되어 있습니다.

### 서명된 URL에 대하여

보고서 다운로드 링크는 보안을 위해 **서명된 URL (Signed URL)** 방식으로 제공됩니다.

| 항목 | 내용 |
|------|------|
| URL 유효 시간 | 생성 후 **1시간** |
| 다운로드 횟수 제한 | 없음 (유효 시간 내 무제한) |
| 만료 후 재발급 | 보고서 목록에서 다시 "다운로드" 클릭 |

> **주의**: 다운로드 링크는 생성 시점으로부터 **1시간** 동안만 유효합니다. 만료된 경우 보고서 목록에서 다시 다운로드 버튼을 클릭하여 새 링크를 발급받으세요.

## 6. 마이페이지

역할에 따라 마이페이지에서 제공되는 기능이 다릅니다.

### 6.1 고객 마이페이지

고객 마이페이지에서는 의뢰한 프로젝트와 관련된 정보를 관리할 수 있습니다.

- **내 프로젝트**: 진행 중/완료된 프로젝트 목록 조회
- **견적서 관리**: 발행된 견적서 확인 및 결제 상태 조회
- **보고서함**: 수령한 보고서 목록 및 다운로드
- **결제 내역**: 결제 이력 및 세금계산서 요청
- **프로필 설정**: 개인정보 및 회사 정보 수정

### 6.2 회계사 마이페이지

회계사 마이페이지에서는 배정된 프로젝트를 관리하고 평가 업무를 수행할 수 있습니다.

- **배정된 프로젝트**: 현재 담당 중인 프로젝트 목록
- **검토 대기**: 자료 검토가 필요한 프로젝트
- **보고서 작성**: AI 초안 기반 보고서 작성 및 수정
- **완료 프로젝트**: 완료된 프로젝트 이력
- **프로필 설정**: 개인정보 및 전문 분야 수정

### 6.3 투자자 마이페이지

투자자 마이페이지에서는 열람 권한이 있는 보고서를 확인할 수 있습니다.

- **보고서 열람**: 열람 권한이 부여된 보고서 목록
- **포트폴리오**: 관심 기업 및 투자 현황 관리
- **알림 설정**: 관심 업종 및 기업 관련 알림 설정
- **프로필 설정**: 개인정보 및 소속 기관 정보 수정

### 6.4 프로필 수정

1. 우측 상단의 프로필 아이콘을 클릭합니다.
2. **"프로필 수정"** 메뉴를 선택합니다.
3. 수정할 항목을 변경합니다.
   - 이름, 연락처, 회사 정보 등
   - **이메일 주소는 변경할 수 없습니다** (계정 식별에 사용)
4. **"저장"** 버튼을 클릭합니다.

> **참고**: 비밀번호 변경은 프로필 수정 페이지의 **"비밀번호 변경"** 섹션에서 별도로 진행합니다.

## 7. 결제 안내

### 결제 수단

현재 ValueLink는 **무통장 입금**만 지원합니다.

### 입금 정보

| 항목 | 내용 |
|------|------|
| **은행** | 우리은행 |
| **계좌번호** | 1005-404-483025 |
| **예금주** | 호수회계법인 |

### 결제 절차

1. 프로젝트 생성 후 **견적 요청**을 진행합니다.
2. 발행된 견적서를 확인합니다.
3. 위 계좌로 견적 금액을 입금합니다.
4. 입금자명은 **프로젝트명 또는 회사명**으로 기재해 주세요.
5. 입금 후 관리자가 확인하면 프로젝트가 다음 단계로 진행됩니다.

### 세금계산서 발급

- 세금계산서 발급이 **가능**합니다.
- 결제 완료 후 마이페이지의 결제 내역에서 **"세금계산서 요청"** 버튼을 클릭하세요.
- 사업자등록번호와 담당자 정보를 입력하면 영업일 기준 1~2일 이내에 발급됩니다.

> **참고**: 카드 결제, 간편 결제 등 추가 결제 수단은 추후 지원 예정입니다.
